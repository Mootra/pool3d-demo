# 123台球

中式八球。先和 AI 打一局，再和朋友开一桌。

[在线试玩](https://mootra.github.io/pool3d/) · [Windows 试玩](https://github.com/Mootra/pool3d/releases/tag/v1.0.0-alpha.11)

![人机对战的全桌视角，球桌上为待开球的母球和十五颗目标球](docs/media/training.webp)

## 先试一局

公开试玩免登录，离线可玩：

- **2D 全桌与 3D 第一人称**，两种视角都能完整打完一局。
- **三档 AI**，局中可换难度，当前球局和比分保留。
- **击球练习**：中袋直球、底袋切球、贴库长球，也可以自己摆球。

## 完整版

完整版是私人版本，只和固定朋友使用，不公开下载。相比公开试玩，多了这些：

- **好友球房**：用预先开好的账号登录，看到四张球桌；点桌卡开桌或入座，也可以直接邀请在线朋友，不用输入房间码。
- **完整对局**：双方准备后开球，每局独立判胜；结算后留在原桌再来一局，开球权轮换。
- **断线回来**：掉线后座位保留两分钟，球继续走；重新登录可以申请接回原局和比分。
- **在线战绩**：只有双方都登录的好友局才计入账号，每局只记一次。
- **球房与聊天**：三套球房风格、菜单音乐；对局中可聊天，新消息只提示、不自动弹出。
- 与公开版相同的 2D/3D、三档 AI、自由球、摆球练习和操作设置。

这不是公开平台：没有路人匹配、公开注册或排位。只有认识的人，和一张安静的球桌。

## 开始

- **浏览器**：桌面 Chrome 或 Edge，鼠标和键盘；3D 需要允许锁定鼠标。
- **Windows x64**：完整解压 ZIP 后运行 `pool3d.exe`，免安装。
